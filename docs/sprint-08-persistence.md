# Sprint 08：工作区重启不丢工作

> 状态：完成。同一 Sprint 还完成了模型接口（[model-port.md](model-port.md)）。Python 测试 195 个全绿。

## 解决什么

Sprint 07 的工作区接口只把成员和审批规则落了盘，工作项还在内存里，服务一重启，进行中的工作就没了。Sprint 08 之后，重启前后完全一样：

| 落盘内容 | 位置 |
|---|---|
| 成员、角色、审批规则 | `<数据目录>/workspace/project.json` |
| 工作项、人工待办、联签进度、退回理由、自检记录、证据日志、成员变更记录 | `<数据目录>/workspace/state.json` |
| 审批请求与决定（一次性、防重放） | `<数据目录>/agent-ops.sqlite3` |

数据目录默认是 `~/.sayelf/agent-ops`，可用 `SAYELF_AGENT_OPS_HOME` 或 `--home` 指定。

## 规则

- 每次提交、人工任务交付、批准或退回、增删成员之后立即保存；先写临时文件再替换，断电也不会留下半个文件。
- 用纯 JSON，不用 pickle：能直接打开看，加载时不会执行任何代码。
- 状态文件读不懂（版本不对、被手改坏）时，服务拒绝启动并报 `STATE_UNREADABLE`，不会悄悄清空大家的待办。
- 自检记录随工作项保存。重启后批准，仍然校验“批准的就是自检过的那一版产出”。
